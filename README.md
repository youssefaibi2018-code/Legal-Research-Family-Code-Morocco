# Legal Guardianship: A Comparative Study ⚖️

## Overview
This repository contains my graduation project titled: **"Legal Guardianship between Maliki Jurisprudence and the Moroccan Family Code (Article 231)"**. 

The research provides an in-depth analysis of the transition and implementation of legal guardianship laws in Morocco, comparing traditional Islamic legal foundations with modern statutory provisions.

## Key Research Focus
* **Article 231 Analysis:** A detailed study of the Moroccan Family Code (Moudawana).
* **Comparative Jurisprudence:** Examining the influence of Maliki Fiqh on modern Moroccan law.
* **Legal Insights:** Critical evaluation of guardianship rights and legal frameworks.
